# 🛒 Superstore Sales Analysis

## Overview
Exploratory data analysis of 9,800 retail transactions from a US-based 
superstore (2014-2017) using Python and Pandas.

## Business Questions
1. Which region generates the most sales?
2. Which category and sub-category is most profitable?
3. What are the monthly and quarterly sales trends?
4. Who are the most valuable customers?
5. Which customer segment spends the most?

## Key Findings
- 💰 **Total Revenue:** $2,261,536
- 🏆 **Top Region:** West ($710,219)
- 📦 **Top Category:** Technology ($827,455)
- 👤 **Top Customer:** Sean Miller ($25,043)
- 📈 **Best Quarter:** Q4 ($871,138)
- 📉 **Weakest Month:** February ($59,371)

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Dataset
- **Source:** Kaggle — Superstore Sales Dataset
- **Size:** 9,800 rows × 18 columns
- **Period:** 2014–2017

## Recommendations
1. Invest in Q1 promotions to boost the weakest quarter.
2. Focus marketing on West and East regions.
3. Create loyalty programs for top customers.
4. Expand Technology product offerings.
5. Target Corporate segment for B2B growth.
